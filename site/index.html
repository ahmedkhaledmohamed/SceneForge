Why it exists

Prompt-by-prompt generation drifts.
Projects shouldn't.

Generate six scenes as six independent prompts and each one finds its own palette, its own light, its own lens. SceneForge captures mood, palette, and lighting once at project creation and composes them into every image and video prompt. Per-scene overrides stay possible; drift doesn't.

The workflow

Profile → scene → publish.

once

Create a profile + character

A profile is your brand — style defaults, recurring characters with reference images, a prompt library, and an asset library. Characters are global: update the refs once, every project uses them.

00:00

New project

Start from scratch, from a saved template, or import a previous backup. Or let the AI Director handle everything: describe a concept and it plans the shot list, generates images, and creates clips automatically.

00:01

Generate images

Multi-reference composition: character refs + scene refs → composed image. LLM-enhanced prompts, multiple options per scene. Use the prompt library to reuse prompts that worked. Draft at $0.003, then one-click upgrade to premium.

00:05

Refine + select

Compare images side by side. Check style consistency with CLIP-based scoring. Keyboard shortcuts (1/2/3) to select. Cost shown before each operation.

00:06

Create clips + audio

Tag shot types (hero, detail, B-roll). Smart routing picks the optimal model per clip based on shot type and budget. Attach ambient sound, music, or voiceover and merge into the clip directly.

00:10

Sequence → export → publish

Arrange clips in the sequence builder, render into one video. Export formatted for TikTok, Reels, Shorts, or Pinterest. AI-generated captions with hashtags. Shop link cards with product URLs. Download or back up the full project as a zip.

What you get

20 features, one pipeline.

AI Director

Describe a concept. AI plans the shot list, generates all images, selects the best, creates clips. One button.

Smart model routing

"Auto" picks the optimal model per clip — Seedance for hero shots, Kling for B-roll — based on shot type and remaining budget.

Draft → Premium

Generate cheap drafts at $0.003. Pick the best composition. One-click upgrade to premium at $0.134. No wasted spend.

Prompt library

Save prompts that worked, tag them, track usage. Reuse across projects. Build your own prompt vocabulary over time.

Asset library

Upload garments, props, and backgrounds once at the profile level. Add them to any scene in any project with one click.

Style consistency scoring

CLIP-based visual similarity across your selected scenes. Green, yellow, red — flag outliers before you render.

Platform export

One-click export formatted for TikTok (9:16, 60s), Reels (90s), Shorts (60s), or Pinterest (2:3). Aspect ratio, codec, duration — handled.

Caption generation

AI-written captions with hashtags and CTA per platform. Tone control: playful, professional, casual, minimal.

Shop link cards

Generate visual "Shop the Look" cards from product URLs in your scene refs. Copy link lists. SRT overlays for timed product callouts.

Audio layer

Attach ambient sound, music, or voiceover to any clip. Preview independently, then merge into the video with one click.

Generation analytics

Cost per kept clip by model. Keep rates. Success rates. Spend trends. Know which model gives you the best ROI.

Backup & portability

Export any project as a zip. Import on another machine. Full profile backup with one click. Projects are folders — no lock-in.

Simple storage

A project is a folder.

No complex database — profiles and projects are plain directories with profile.json and project.json next to your media. Export any project as a zip, import it anywhere. Deploy on Railway, run locally, or self-host with Docker. 100 endpoints, 279 tests.
