1Accounts & Login

SceneForge supports three ways to sign in:

  • Google — click "Continue with Google" on the login page. Uses your Google name and avatar.
  • GitHub — click "Continue with GitHub". Uses your GitHub name and avatar.
  • Email + password — create an account with any email and a password (at least 8 characters).

Each sign-in method creates a separate account. If you sign in with Google and then with GitHub using a different email, those are two different accounts with separate profiles.

After logging in, you land on your dashboard — it shows total spend, recent projects across all profiles, and your profile list. SceneForge remembers your last profile and can auto-redirect you there on login. You can switch between profiles using the dropdown in the top navigation bar.

2Profiles

A profile is your brand or workspace. Think of it as a container for everything related to one content identity:

  • Characters — your recurring subjects (a doll, a model, a mascot) with reference photos
  • Style defaults — the visual look that gets applied to every image (lighting, colors, mood)
  • API keys — your Together AI and OpenRouter keys for AI generation
  • Projects — individual posts or videos, each with their own scenes and clips
  • Prompt library — saved prompts you can reuse
  • Asset library — garment photos, backgrounds, and props you use across projects

Creating a profile: Click "New profile" on the profile list page. Give it a name (e.g. "GenerationStyled"). The name becomes the URL slug.

Style anchor: At the top of the profile page, set your style — this text gets automatically added to every image generation prompt. Example: "soft golden hour light, muted earth tones, clean background". You set it once; every project inherits it.

Why multiple profiles? If you run different content brands with different characters and styles, each gets its own profile. Most people need just one.

3Characters

A character is a recurring subject in your content — typically a doll, figurine, or model that appears across all your posts. Characters live at the profile level, so every project can use them.

Adding a character

On your profile page, use the form at the top: enter a name and upload one or more reference photos. These photos teach the AI what your character looks like.

Reference photos — what works best

  • Upload 3-5 clear photos of the character from different angles
  • Well-lit, clean background, the character should fill most of the frame
  • Include at least one full-body shot and one close-up
  • You can add more reference photos later by clicking "+ref" next to the character name

Main character

The first character you add becomes the main character (marked with a star). When you create scenes without specifying a character, the main character is used automatically.

How characters work in generation

When you generate an image for a scene, the AI receives your character's reference photos along with the scene description, garment references, and style anchor. This is what keeps your character looking consistent across all your content — the AI is always looking at the same reference photos.

4Projects

A project is one piece of content — typically one post, one video, or one look. Inside a project you have scenes (visual moments), generated images, video clips, and export settings.

Creating a project

Three ways to start:

  • New project — blank project. Give it a name and a concept (e.g. "spring pastel outfit for toddler boy").
  • From template — start with a pre-built structure. Three built-in templates:
    • Product lookbook — 8 scenes: hero shot, detail close-ups, outfit shots, flat lay, lifestyle
    • Day in the life — 6 scenes: morning to evening progression
    • Character series — 6 scenes: character in different contexts and poses
  • Import from zip — restore a previously exported project backup

The project creation form shows which settings are inherited from your profile (image model, video model, aspect ratio, image options) with a "from profile" label so defaults are never invisible.

Project concept

The concept is a short description of what this post is about. It's used by the AI Director, shot list generator, and caption generator. Example: "toddler boy spring outfit — pastel blue polo, khaki shorts, white sneakers".

Project list

The project list shows thumbnails (from your first selected image), spend per project, and "updated 2h ago" relative timestamps. Each project card gives you a visual preview of what's inside without clicking in.

Budget

You can set a USD budget for the project in settings. When set, SceneForge will warn you before operations that would exceed the budget, and smart model routing will pick cheaper models as you approach the limit.

5Scenes & References

A scene is one visual moment in your project — one image that will become one or more video clips. Each scene has:

  • A description — what's happening in this scene (e.g. "standing in a sunlit cafe, full outfit visible")
  • A pose (optional) — how the character is positioned (e.g. "standing, facing camera, head to toe")
  • A character — which character appears in this scene
  • Reference images — photos of the specific garments, accessories, or props in this scene

Adding reference images

Reference images are the most important part of getting good results. These are the actual product photos — the garment, shoes, accessories — that the AI uses to dress your character.

  • Drag and drop product photos directly onto a scene card
  • Or click the file upload area on the scene card
  • Each ref has a role: garment, style, background, prop, or other
  • Each ref can have a label (e.g. "Blue Polo") and a shop URL (for link cards later)
  • You can also add refs from your asset library — click "from library" on the scene card

How many refs?

Each scene can have up to 14 reference images (with the nano-banana-pro model) or 8 (with flux-2-pro). More refs = more specific result. Typical setup: 1 character (from profile) + 3-5 garment/accessory photos per scene.

Adding scenes

  • Manually — click "+ scene" and describe the moment
  • Brainstorm — the AI suggests scene ideas based on your concept
  • Shot list — the AI generates a complete list of scenes with compositions and shot types (see AI Director)

Reordering scenes

Use the up/down arrows on each scene card to reorder them. Scene order determines the sequence of your final video.

6Generating Images

Once a scene has a description and reference images, click Generate on the scene card. SceneForge composes a prompt from:

  1. Your style anchor (from the profile)
  2. The character description + reference photos
  3. The scene references (garment photos, props)
  4. The scene description and pose

All of this is sent to the AI model together — the model sees the character, the clothing, and the scene description, and generates an image that combines them.

Image options

By default, SceneForge generates 2-3 options per scene so you can pick the best one. You can change this number in project settings.

Choosing a model

Each scene card has a model picker. The main image models:

7Prompt Enhancement

When you write a short scene description like "standing in a cafe", SceneForge can automatically enhance it into a detailed generation prompt using an LLM.

The enhanced version might become: "A character standing in a cozy cafe interior, warm natural light streaming through large windows, wooden tables and chairs in the background, a ceramic mug on the counter, shallow depth of field, shot from slightly below eye level".

How to use it

  • Click the Enhance button next to a scene description
  • The enhanced prompt appears in an editable text area — you can accept or discard it
  • Or enable Auto-enhance in project settings to enhance every prompt automatically

Enhancement uses your style anchor, character info, and garment labels to write a prompt that's specific to your content — not generic.

8Selecting & Comparing

After generating multiple image options for a scene, you need to pick the best one.

How to select

  • Click on any image to view it full-size in the lightbox
  • Use keyboard shortcuts 1, 2, 3 to quickly select option 1, 2, or 3
  • The selected image gets a gold border and is used for video clip generation
  • Select all button auto-selects the first image in every scene (useful for quick workflows)

Comparing

When you have multiple options, SceneForge shows them side by side on the scene card. Click any image to compare at full size.

9Draft to Premium Upgrade

Generate cheap drafts first, then upgrade only the ones that work.

The workflow

  1. Generate images with flux-schnell or flux-2-pro (cheap)
  2. Pick the composition you like
  3. Click Upgrade on that image — it regenerates with nano-banana-pro (better quality, same composition)

This saves money: instead of generating 3 options at $0.134 each ($0.40), you generate 3 drafts at $0.03 ($0.09), then upgrade 1 ($0.134) = $0.22 total.

Upgrade also works on video clips — upgrade a Kling clip to Seedance for better motion quality.

10Video Clips

Switch to the Clips tab to create video clips from your selected images.

Creating a clip

  1. Click + clip
  2. Pick a start image from any scene (the first frame of the video)
  3. Optionally pick an end image (the AI interpolates between them)
  4. Write a motion prompt — what should move? (e.g. "gentle wind blows the dress, character turns slightly")
  5. Set duration (3-10 seconds)
  6. Pick a model (or use Auto — see Smart Routing)
  7. Click Generate

Video models

seedance-2.0Most realistic motion$0.52-0.80/clip

Keep / discard

After a clip generates, watch the preview. Click Keep to mark it as a keeper — only kept clips appear in the sequence builder and export. You can generate multiple clips from the same image and keep the best one.

Multiple clips per scene

You'll often want several clips from the same image with different motion prompts. For example, from a standing outfit shot: one clip with the character turning, one with wind blowing the outfit, one with a slight camera pan. Create a separate clip for each.

11Shot Types & Smart Routing

Shot types categorize your clips by their role in the final video:

  • Hero — the main money shot, your best angle. Uses premium models.
  • Detail — close-up on texture, label, or stitching
  • B-roll — supplementary footage, lifestyle context. Uses cheaper models.
  • Transition — connecting shots between scenes
  • Wide — full-body or environment establishing shot
  • Overhead — top-down flat lay angle

Smart routing (Auto mode)

When you set a clip's model to Auto, SceneForge picks the best model based on the shot type and your remaining budget:

  • Hero shots → seedance-2.0 (best quality)
  • B-roll → kling-2.1 (cheapest)
  • Detail → seedance-1.5-pro (good value)
  • If your budget is running low, it automatically downgrades to cheaper models

Set the shot type on each clip card using the dropdown, then use Auto for the model.

12Batch Generation

Instead of generating one scene or one clip at a time, you can batch everything:

Generate all scenes

In the Scenes tab, click "Generate all scenes". This generates images for every scene that doesn't have them yet, running in parallel. You see a progress bar and cost estimate before starting.

Generate all clips

In the Clips tab, click "Generate all clips". This creates and generates clips for all scenes with selected images. Uses smart routing if set to Auto.

Produce (full pipeline)

The Produce button at the top runs the entire pipeline in one click:

  1. Generate images for all scenes missing them
  2. Auto-select the best image per scene
  3. Create and generate clips for each scene

Shows a cost estimate before starting and progress through each stage.

13AI Director

The AI Director is the one-button experience. You give it a concept, and it does everything:

  1. Plans a shot list — the AI decides what scenes to create, with descriptions, compositions, and shot types
  2. Generates images for every scene
  3. Selects the best image per scene
  4. Creates clips from the selected images

How to use it

  1. Create a new project with a clear concept
  2. Click Direct at the top of the project page
  3. Adjust the number of scenes (default 8) and clip duration
  4. Click "Action" — then wait for the pipeline to complete

The AI Director is great for quick content when you don't need precise control over each scene. You can always edit the results afterward — change descriptions, regenerate specific scenes, or adjust clips.

Shot list generator (manual alternative)

If you want to review the plan before generating, use "Shot list" instead. The AI creates a list of scenes with descriptions, compositions, and shot types. You can edit, remove, or reorder scenes before applying them.

14Sequence Builder

Switch to the Sequence tab to arrange your kept clips into the final video order.

Building a sequence

  • Completed clips appear in the "Available clips" section at the bottom
  • Click + add to add a clip to the sequence
  • Use the up/down arrows to reorder clips in the sequence
  • Click x to remove a clip from the sequence (doesn't delete the clip)

The sequence shows total duration and each clip's duration.

Rendering

Click Render sequence to stitch all clips into one continuous video. SceneForge normalizes resolution, applies crossfade transitions, and outputs a single MP4 file.

15Audio Layer

Add audio to individual clips before or after rendering.

How to use

  • On each completed clip card, you'll see an audio section
  • Choose an audio type: Ambient (background sounds), Music (background beat), or Voiceover
  • Click Add audio and upload an audio file (MP3, WAV, M4A, or MP4)
  • The audio file attaches to the clip — you can preview it
  • Click Merge into clip to combine the audio with the video permanently
  • Click Remove audio to detach it

Note: For most social media content, you'll want to add music directly on TikTok/Instagram after uploading (better trending audio selection). The audio layer is most useful for ambient sounds or voiceover narration.

17Captions & Hashtags

SceneForge uses AI to generate social media captions with hashtags and a call-to-action for each platform.

Generating a caption

  1. Scroll down in the Sequence tab to the Caption section
  2. Pick a platform (Instagram, TikTok, YouTube, Pinterest)
  3. Pick a tone (Playful, Professional, Casual, Minimal)
  4. Click Generate caption

The AI writes a caption using your project concept, scene descriptions, and product references (including shop URLs if you added them). It generates:

  • Caption text — editable in a text area
  • Hashtags — shown as pills, click to remove any you don't want
  • CTA (call to action) — like "Shop the look: link in bio"

Click Copy to clipboard to copy the full caption + hashtags ready to paste into your post.

You can generate captions for multiple platforms — each is saved separately.

18Shop Link Cards

If your scenes have product references with shop URLs, SceneForge can generate visual product cards and link lists for your posts.

Setting up shop links

When adding a reference image to a scene, fill in the URL field with the product's shop link. Also add a label (e.g. "Blue Polo Shirt").

Features

  • Generate link card — creates a "Shop the Look" PNG image showing all products with thumbnails and short URLs. Download and include in your carousel or story.
  • Copy link list — copies a numbered list of product names and URLs to your clipboard. Paste into your post caption or link-in-bio.
  • Download overlay (.srt) — generates a subtitle file that times product names to appear during their scene in the video. Import into your video editor for timed product callouts.

The Shop Links section only appears when you have scene references with URLs.

19Prompt Library

Save prompts that produced good results so you can reuse them across projects.

How to use

  • In the Scenes tab, click Prompt library in the toolbar
  • The library panel slides open showing your saved prompts
  • Save a prompt: type the prompt text, add comma-separated tags (e.g. "fashion, golden-hour, cafe"), click Save
  • Use a prompt: click "Use" — it copies the text to your clipboard. Paste it into a scene description.
  • Filter by tag: use the dropdown to filter prompts by tag
  • Usage tracking: each prompt shows how many times it's been used

Prompts are saved at the profile level, so they're available in every project under that profile.

20Asset Library

Upload garment photos, backgrounds, and props once and reuse them across all your projects.

Uploading assets

Assets are uploaded at the profile level. Each asset has:

  • An image file
  • A label (e.g. "White Sneakers")
  • A role — garment, style, background, prop, or other
  • Tags for filtering
  • An optional URL (shop link)

Using assets in scenes

On any scene card, click "from library". A picker appears showing your assets filtered by role. Click any asset to add it as a reference to that scene — the file is copied into the project so the project stays self-contained.

The asset library tracks which projects have used each asset.

21Project Templates

Save a project's structure (scenes, shot types, descriptions) as a reusable template — without the generated media.

Built-in templates

  • Product lookbook (8 scenes) — hero, detail close-ups, outfit shots, flat lay, lifestyle, BTS
  • Day in the life (6 scenes) — morning routine through evening wind-down
  • Character series (6 scenes) — character in multiple contexts and poses

Custom templates

After you've set up a project with scenes you like, go to the project header and click "Save as template". Give it a name. Next time you create a project, choose "From template" and select yours.

Templates save: scene descriptions, shot types, and style settings. They don't save generated images or clips — those are regenerated for each new project.

22Analytics

Click Analytics in the top navigation to see generation stats across all your projects.

What you see

  • Total spend — how much you've spent on AI generation
  • Average cost per kept clip — the real ROI metric. If you generate 5 clips and keep 1, this is your true cost per usable clip.
  • Best value model — which model gives you the lowest cost per kept clip
  • Spend trend — bar chart of weekly spending
  • Model performance table — for each model: images generated, clips generated, keep rate, success rate, total spend, and cost per kept clip

Use this to optimize your model choices. If Kling has a 80% keep rate at $0.18/clip and Seedance has a 60% keep rate at $0.52/clip, Kling is giving you better value — $0.23/kept vs $0.87/kept.

23Style Consistency Scoring

Before rendering your final video, check that all your scenes have a consistent visual style.

How it works

Click "Check consistency" in the project header (appears when you have 2+ scenes with selected images). SceneForge uses AI (CLIP embeddings) to measure how visually similar your scenes are to each other.

Reading the results

  • Green (80%+) — your scenes look cohesive, good to render
  • Yellow (60-80%) — some scenes drift from the group. Check the flagged outliers.
  • Red (below 60%) — significant visual inconsistency. Consider regenerating outlier scenes with the same style anchor.

Outlier scenes are flagged with their similarity score. You can regenerate those scenes or adjust their style override to match the rest.

24Backup & Export

Export your projects as zip files for backup or to share with someone.

Project backup

In the project header, click "backup zip". Downloads a zip containing:

  • The project data (scenes, clips, settings)
  • All reference images
  • Selected/kept images and clips
  • A manifest with project stats

Full profile backup

On the profile list page, click "Backup all". Downloads a single zip with all your projects.

Importing

On the profile list page, click "Import zip" and select a previously exported backup zip. It creates a new project with all the data restored.

25Settings & API Keys

Click Settings in the top navigation to manage your profile settings.

API keys

SceneForge uses external AI services for generation. You need at least one key:

  • Together AI — required for image generation (FLUX models) and some video models. Get a key at api.together.ai
  • OpenRouter — optional, for cheaper Seedance video clips. Get a key at openrouter.ai/keys
  • RunPod — optional, for self-hosted GPU generation (advanced)

Keys are stored in your profile directory on the server. They override any server-level keys.

Account status

Settings shows your API account status — whether your Together AI and RunPod keys are valid and your current credit balance.

Account info

Shows your login method (Google, GitHub, or email), name, and email address.

26Account Dashboard

The /app page is your account-wide dashboard. It shows:

  • Summary cards — total profiles, total projects, and total GPU spend across all your brands
  • Recent projects — the 5 most recently updated projects across all profiles, with thumbnails, profile name, and relative time. Click to jump directly into any project.
  • Profile grid — all your profiles with spend badges and "updated Xh ago" timestamps

The dashboard gives you a single view of everything you're working on, without needing to open each profile separately.

27Activity & Timestamps

Every project tracks created_at and updated_at timestamps. The updated_at timestamp bumps automatically every time you make a change — add a scene, generate an image, keep a clip, etc.

Where you see timestamps

  • Project list — "updated 2h ago" on each project card
  • Profile list — shows the most recent update across all projects in that profile
  • Dashboard recent projects — sorted by most recently updated

Timestamps help you quickly find what you were working on last, especially when you have many projects across profiles.

28Preferences & Memory

SceneForge remembers your preferences across sessions:

  • Last profile — when you log in, SceneForge auto-redirects to the profile you used last time. Click the wordmark "SceneForge Studio" to go back to the full dashboard.
  • Profile switching — the dropdown in the top bar shows all your profiles. When you switch, the app clears the previous profile's cached data so you never see stale content from another brand.
  • Loading states — while data loads, you see smooth skeleton placeholders instead of blank pages. Cards, headers, and tabs all have matching placeholder shapes.
  • Stats updates — when you create, delete, or generate content, profile stats and project counts update immediately without needing to refresh the page.

Preferences are stored server-side in your account, so they persist across devices and browsers.
