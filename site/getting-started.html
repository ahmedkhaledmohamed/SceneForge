Getting started

First video in
ten minutes.

SceneForge is a web app with multi-user accounts. Sign up with Google, GitHub, or email. You'll need a Together AI key for image generation and optionally an OpenRouter key for cheaper Seedance video clips. See pricing for a full cost breakdown, or check the features guide for detailed documentation.

1Sign up

Click Login in the top right. Sign up with Google, GitHub, or an email + password. After signing in, you land on your dashboard — it shows your profiles, total spend, and recent projects across all your brands.

2Create a profile

Click New profile. A profile is your brand workspace — it holds your characters, style defaults, API keys, prompt library, and asset library. Give it a name (e.g. "GenerationStyled") and you're in.

Set your style anchor at the top of the profile page — this text gets prepended to every image generation prompt automatically. Example: "soft golden hour light, muted earth tones, clean background".

3Add your API keys

Go to Settings and paste your Together AI key. This is the only required key — it powers all image generation and some video models. Optionally add an OpenRouter key for cheaper Seedance video clips.

4Add a character

On the profile page, add a character — your recurring subject (a doll, model, mascot). Upload 3-5 clear reference photos from different angles. Characters are global: update the refs once, every project uses them.

Profile character (recurring subject) → sent to every scene using that character
       ↓
Scene refs (product photos, style)    → owned by the scene, dropped onto the card
       ↓
Asset library (reusable garments)     → uploaded once, added to any scene
       ↓
AI generation = character + scene refs + style anchor → composed image

5Create a project

Each project is one piece of content — a post, a video, a look. Three ways to start:

  • New project — blank canvas. Give it a name and concept.
  • From template — use a pre-built structure (Product lookbook, Day in the life, Character series).
  • AI Director — describe your concept and AI plans the entire shot list, generates images, and creates clips automatically.

The project creation form shows which settings are inherited from your profile (image model, video model, aspect ratio) so you always know what defaults you're getting.

6Add scenes + reference images

Each scene is a visual moment. Describe it (e.g. "standing in a sunlit cafe, full outfit visible") and drop reference images onto the scene card — garment photos, props, backgrounds. You can also add refs from your asset library with one click.

Shortcuts: use Brainstorm to get AI-suggested scene ideas, or Shot list to generate a complete list of scenes with compositions and shot types.

7Generate images

Click Generate on a scene card. The AI combines your character refs, scene refs, and style anchor into a composed image. You get 2-3 options per scene. Use prompt enhancement to auto-expand short descriptions into detailed prompts.

Cost-saving tip: generate drafts with flux-schnell ($0.003), pick the best composition, then one-click upgrade to nano-banana-pro ($0.134) for the final version.

8Select + compare

Click images to view full-size in the lightbox. Use keyboard shortcuts 1, 2, 3 to select quickly. Check style consistency (CLIP-based scoring) to verify all your scenes have a cohesive look before rendering — green means good, yellow/red flags outliers.

9Create video clips

Switch to the Clips tab. Pick a start image, set a motion prompt, choose a model (or use Auto for smart routing based on shot type and budget), and generate. You can create multiple clips from the same image with different motions. Tag each clip with a shot type (hero, detail, B-roll) for smart model selection.

10Build the sequence

Switch to the Sequence tab. Add kept clips, drag to reorder, preview the timeline. Click Render sequence to stitch everything into one video with crossfade transitions. Add audio (ambient, music, voiceover) to individual clips before rendering.

11Export + publish

Use the "Export for..." dropdown to re-encode for TikTok, Reels, Shorts, or Pinterest — each platform gets the right aspect ratio, codec, and duration limit.

Generate AI captions with hashtags per platform (playful, professional, casual, minimal tone). Create shop link cards from your product URLs. Copy the caption + links, upload the video, publish.

12Track your spend

The Analytics page shows cost per model, keep rates, cost per kept clip, and spend trends. Your dashboard at /app shows total spend across all profiles. Every generation button shows the estimated cost before you click.

13Backup + restore

Click "backup zip" on any project to download a complete backup (project data + refs + kept media). Click "Backup all" on the profile page to back up every project at once. Import backups with "Import zip" on the project list page.

14Try for free

The fake models run the entire pipeline for $0 — real files, zero API cost. Good for testing the workflow before spending. The demo mode on the landing page also lets you explore the Studio without an account.
